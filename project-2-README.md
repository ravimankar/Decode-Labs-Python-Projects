Expense Tracker

Project Description

This is a simple Python Expense Tracker that allows users to enter their expenses and calculates the total amount spent.

Features

- Add multiple expenses
- Enter expenses until typing "done"
- Automatically calculates the total amount spent

Technologies Used

- Python

How to Run

1. Make sure Python is installed on your computer.
2. Run the Python file.
3. Enter your expenses.
4. Type "done" when you have finished entering expenses.
5. The program will display the total amount spent.

Example

Enter expense (or 'done' to finish): 100
Enter expense (or 'done' to finish): 250
Enter expense (or 'done' to finish): done

Total Spent: 350.0
